⚠ SOS gesture

Make a closed fist and hold it for 3 seconds to trigger an emergency alert — or use the button below any time. Camera-based detection can miss, so the manual button is always the reliable option.

Prototype notice: this build classifies a fixed set of static hand shapes from MediaPipe's hand-landmark model using geometric rules — it does not cover ISL's full vocabulary, the full range of two-handed signs, motion-based signs, or facial grammar, and isn't a substitute for a professional interpreter. All video processing happens locally in your browser; nothing is uploaded. The SOS gesture is a convenience layer, not a certified emergency system — for real emergencies use the manual SOS button or dial your local emergency number directly.
